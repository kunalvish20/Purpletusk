# Purple Tusk Storefront

React + Vite storefront restyled around the supplied Purple Tusk identity.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Main brand assets

- `public/brand/purple-tusk-logo.png`
- `public/brand/purple-tusk-elephant.png`
- `public/curve-line-pink.png`
- `public/banners/purple-tusk-festive.png`
- recolored desktop/mobile campaign banners under `public/banners/`

The website uses a raspberry-pink, deep berry, blush, and warm-cream system derived from the supplied logo. The looping hero wave is retained on desktop and mobile.
